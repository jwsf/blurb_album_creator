# Blurb Template Files

This directory is the location for Blurb Bookwright template `.blurb` files used by this toolset. The template files are not included in this repository.

## Downloading Templates

Download templates directly from Blurb:

**[https://www.blurb.com/templates](https://www.blurb.com/templates)**

Open each template in Bookwright, then locate the saved `.blurb` file on your machine and copy it here. Bookwright saves projects to:

- **macOS**: `~/Documents/Bookwright 6/Projects/`

## Recommended Templates

The scripts in this project work with any Bookwright template. The following template names are referenced in examples:

| File | Description |
|---|---|
| `FamilyBook-StandardLandscape.blurb` | Family Book, Standard Landscape |
| `FamilyBook-StandardPortrait.blurb` | Family Book, Standard Portrait |
| `FamilyBook-LargeLandscape.blurb` | Family Book, Large Landscape |
| `TravelBook-StandardLandscape.blurb` | Travel Book, Standard Landscape |
| `TravelBook-StandardPortrait.blurb` | Travel Book, Standard Portrait |
| `TravelBook-LargeLandscape.blurb` | Travel Book, Large Landscape |

## Why Not Included

Blurb template files are proprietary. They are not redistributed here out of respect for Blurb's intellectual property.
